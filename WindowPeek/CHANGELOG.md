# Window Peek 0.2.1

- 修复多个 Chrome 窗口大小、位置相同时，标题正常但预览图无法显示的问题。
- 优化预览出现过程：先确定面板尺寸，首屏截图准备好再显示，减少加载文字、面板伸缩和图片切换造成的闪动。
- 长按时间调整为 0.15 / 0.25 / 0.4 / 0.6 秒，默认 0.25 秒；旧设置会自动对应调快一次。
- 修复面板等待显示时，点击其他窗口后仍可能弹出的问题。

## 安装与兼容性

适用于 **Apple Silicon、macOS 14 及以上**。下载 DMG 后，将应用拖到 Applications；更新前先从菜单栏退出旧版本。已有用户若安装在 `~/Applications`，请替换原位置，避免保留多个副本。

首次使用需要辅助功能和录屏权限。

同名且完全重叠、最小化或受保护的窗口，仍可能无法生成预览。
