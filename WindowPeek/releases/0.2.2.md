# Window Peek 0.2.2

本次更新修复窗口预览问题，并改进安装引导：

- 打开预览时，面板和中间缩略图区域不再出现两侧向内收缩的闪动。
- 修复 Chrome 多窗口预览不完整的问题。同名、相同大小和位置的窗口，也能分别显示预览；切换当前窗口后，其他窗口的预览不再因此消失。
- 修复一个窗口被显示成两个的问题，避免将辅助浮动面板误算为可切换窗口。

- 新增清晰的拖拽安装界面：应用在左、Applications 在右，配有箭头引导；移除单独的安装说明 TXT。

## 安装与兼容性

适用于 **Apple Silicon、macOS 14 及以上**。更新前先从菜单栏退出旧版，再替换原安装位置的应用；如果之前安装在 `~/Applications`，请继续使用该位置，避免保留多个副本。

首次使用需要辅助功能和屏幕录制权限。最小化、受保护或系统无法提供画面的窗口，仍可能显示预览占位；可正常枚举的窗口会继续保留在切换列表中。

安装包已使用 Developer ID 签名并通过 Apple 公证，附带 SHA-256 校验文件。
